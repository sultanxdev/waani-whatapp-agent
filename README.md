# 🚀 Zendev.dev (Under Development)

🚧 **Work in Progress** — Zendev.dev is an AI-powered MVP generator that helps solo founders and developers turn a simple prompt into a full-stack application scaffold.

Build frontend, backend, authentication, database models, and deployment configuration from a single idea.

---

## Product Overview

**Name:** Zendev.dev  
**Tagline:** Build full-stack MVPs from a single prompt.  
**Mission:** Reduce the time and complexity required to go from idea to a working MVP by automating repetitive full-stack setup using AI.

---

## Current Status

- Product concept and scope defined  
- Feature set and generation flow planned  
- Tech stack finalized  
- Core generation logic under development  
- Not production-ready  

---

## Problem

Building an MVP usually requires:
- Setting up frontend and backend separately  
- Designing database schemas manually  
- Implementing authentication from scratch  
- Configuring deployment and environment setup  

This process is time-consuming, repetitive, and slows down experimentation for solo founders and indie developers.

---

## Solution

Zendev.dev provides an AI-driven workflow to:
- Convert a product idea into a structured codebase  
- Generate frontend, backend, auth, and database layers together  
- Provide a deploy-ready starting point instead of empty boilerplate  

The goal is **speed, consistency, and reduced cognitive load** during early-stage product development.

---

## Key Features (Planned)

- Prompt-to-App Generation (idea → codebase)  
- Frontend generator with React and Tailwind CSS  
- Backend API generator using Node.js and Express  
- JWT-based authentication module  
- Database schema generation (MongoDB)  
- Deployment configuration for common platforms  
- AI chat assistant to refine or regenerate components  

---


Design goals:
- Modular generators  
- Clear separation of concerns  
- Extendable templates  
- Developer-readable output  

---

## Tech Stack

- **Frontend:** React.js + Tailwind CSS  
- **Backend:** Node.js + Express  
- **Database:** MongoDB Atlas  
- **AI Engine:** OpenAI (GPT-based models)  
- **Deployment:** Vercel (frontend), Render (backend)  
- **Auth:** JWT (OAuth planned)
